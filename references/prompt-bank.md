# 提示词模板库（Prompt Bank）

用法：先按图纸类别选模板（机房 / 线路 / 天线），把 `【】` 占位替换为本图实际信息。`image_reference_url_list` 按"风格参考图 + 信息源干净图"顺序传入；只有一张原图时传一张。宽高与原图一致。

## 通用必带要素（每套模板都保留，均为强制要求）

- 布局、图元位置、名称、编号、尺寸/标高/坐标对应原图，不遗漏、不颠倒上下游。
- **单色批注【强制】**：全图只能有黑色铅笔线稿 + 仅一种批注色（默认红笔）；原图红/黄/紫/蓝/绿等所有彩色批注必须全部并入该色，严禁出现第二种彩色，严禁保留多色。
- **参差手写【强制】**：文字高低上下参差、基线起伏不成行、字号大小不一、微微歪斜、字距松紧不均；严禁印刷体、严禁工程仿宋、严禁整齐排版与对齐成行。
- 线条手抖抖动、略带重描；纸面有轻微铅笔灰影、擦除痕和污渍。

### 通用风格强化块（每套模板都应包含）

```
工程现场笔记 / 白板草稿质感；像是用手机拍下的一张现场草图纸：纸张整体轻微斜放 1-3°、四边略出画；米白纸面有隐约纸纹（paper tooth），1-3 道横向折痕带淡阴影、纸面略鼓起，另有淡污渍水渍、右下或右上指印、铅笔拖擦灰迹、橡皮擦过的淡白痕，纸边可有撕口或胶带痕，光照自左上略不均、中部偏亮、边缘稍暗；画面里只出现纸，不出现桌面、手、笔。三层线宽：主线略粗炭灰、标注引线细、强调线最粗（仅重点 2-3 处）；前景粗、背景细，次要结构用断续虚线。构造辅助线最淡，主体轮廓中等铅色，涂黑柱/重点阴影重压；阴影只用 45° 稀疏交叉排线，不上色块。文字分三级：图名最大、设备/站名次之、编号坐标尺寸最小；线条有自然粗细变化和轻微不完美，organic line variation。
```

### 通用负面约束块（每套模板都应追加）

```
排除：写实场景照片（桌面/手/笔/工具摆拍）、3D 渲染、CGI、图库配图、光滑数码矢量、digital pen tool、clean vector、完美笔直的线、完美对称、几何精准、机械一致的线条、平滑贝塞尔曲线、完美圆形、印刷教材感、渐变填充、喷枪质感、立体光影、材质反射、商业海报排版；保持纯线稿，不上色块、不做灰度渐变。
```

## 迭代调整短语（追加到提示词末尾）

- 手写再参差：`文字必须更像真人随手写：每个字高低错落、基线明显起伏，不要对齐成行，字号大小不一、略微歪斜。`
- 更凌乱：`加重反复重描、涂改黑块和擦除痕迹，辅助涂鸦再多一些。`
- 更易读：`减少涂改和乱线，设备名称与编号写清楚、可辨认，但仍保持参差手写。`
- 换批注色：`批注色由红笔改为【蓝笔】，全图仍只用这一种批注色。`
- 去批注色：`全部黑白铅笔线稿，去掉所有彩色批注。`
- 保留墙体厚度：`外墙按原图绘制双线，表现墙体厚度。`
- 工整笔记档：`线条收稳、文字偏清楚、涂改少，手写参差幅度减小，像整理过的现场笔记。`
- 减少填充阴影：`不要任何色块和灰度阴影，只保留轮廓线和少量铅笔排线。`
- 线条再放松：`线条再放松一些，允许轻微抖动和出头，不要描得过于规整。`
- 破除太规整：`线条加入有机不完美和轻微手抖，形状略微不对称，不要尺画直线和几何精准感。`
- 收住太乱：`落笔 deliberate、位置明确，减少潦草乱线和多余涂改，名称编号清楚可辨，仍保留参差手写。`
- 去数码矢量感：`改成铅笔在纸上的纯线稿质感，去掉光滑矢量边、数码笔触感和平滑贝塞尔曲线，保留米白纸纹。`
- 拆分超长图：`本图过长，只画【上半段/左半段】，右侧（下侧）留出接续位置，并在断口手写"接下图"。`
- 补尺寸：`把图上每一个尺寸数字都手写标到对应尺寸线旁（【逐条列出】），一个不许漏。`
- 只显示单色：`全图只有黑铅笔与红笔两种颜色，任何蓝色、黄色、绿色、紫色都不要出现。`
- 加褶皱：`纸张再真实些：纸面有 2-3 道横向折痕、折痕两侧带淡阴影，纸边略卷、纸面微鼓。`
- 加污迹：`纸面加淡污渍、水渍边缘、右下角指印和铅笔拖擦灰迹，橡皮擦过处留淡白痕。`
- 照片更真：`像手机随手拍的一张草图纸：纸张斜放 1-3°、四边略出画、光照自左上略不均、中部偏亮边缘稍暗，只有纸不入桌面和手。`
- 回到干净稿：`去掉折痕、污渍与斜放，改成平整的干净扫描版，其余手绘规则不变。`

## 提示词避坑

- 不要写"规整、整齐、工整、规范、标准、对齐、表格线、印刷、矢量化"——模型会照做，直接出成印刷图。
- 同一句里不要既写"凌乱狂草"又写"清晰可读"，两个方向会互相抵消；乱度和可读性分两次迭代调。
- 每轮只改一个变量，便于判断是哪句话起的作用。
